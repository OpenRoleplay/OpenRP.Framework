# The phone menus

`/phone` opens the menu of the phone you carry. Carrying several, you first pick one, shown with its number and what's new.

## The menu

| Row | Does |
|---|---|
| Dial a number | Asks for a number, then calls it |
| Redial | Calls the last number you dialed |
| Phone book | Your contacts. See below |
| Messages | Your texts; shows "(2 new)" when there are unread ones |
| Call log | Missed, received and dialed calls; shows "(1 missed)" |
| Ringer | On or Silent. Silent means no `/do`: only you notice |
| My number | Shows the phone's number |
| Turn off | Calls can't reach it, but texts wait until it's on |

A phone that's off only has "Turn on". Turning it on tells you what came in.

## Phone book
- **Add a name:** a name (at most 24 characters), then the number.
- **A contact:** Call, Send a message, Rename or Delete.
- Contact names show instead of numbers everywhere: calls, texts and the call log.

## Messages
- **Write a message:** the number, then the text (at most 160 characters).
- **The list:** unread first, marked `[New]`, then newest first.
- **A message:** shows who it's from or to, when, and the text. Opening it marks it read. "Options" has Reply, Call, Save the number and Delete.

## Call log
- **The list:** `Missed`, `Received` or `Dialed`, with the time and, for answered calls, the duration. New missed calls are marked `[New]`.
- **Opening it** marks the missed calls as seen.
- **A call:** Call back, Send a message, or Save the number.

## Incoming calls
A dialog pops up with the caller, with **Answer** and **Decline**. You can also use `/answer` and `/hangup`.
